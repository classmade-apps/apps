    How the lesson timer works

    The lesson timer is a free online timer for a whole class period. List your activities in order, give each one a length in minutes, then select Start lesson. Each countdown starts automatically when the previous one ends, so you don’t have to reset a timer between activities. The display shows the current activity, the time left, and what comes next.

    If you teach more than one class, select New class to create a named plan. Choose the plan you want from the Class plan dropdown before starting. Each class keeps its own activities and durations.

    Select Fullscreen to put the display on a projector or classroom screen. Use Pause when a discussion runs long, Skip activity to move on early, and Reset lesson to start the plan from the top. Turn on a gentle or bright chime if students need an audible cue when it’s time to switch.

    Sample lesson plans

    The starter plan is a 45-minute lesson: bell ringer (5 min), partner work (10 min), direct instruction (20 min), exit ticket (5 min), and homework (5 min). Edit the names and times to fit your class.

    For a 50-minute literacy block, try: read-aloud (10 min), mini-lesson (10 min), independent reading (20 min), turn and talk (5 min), and cleanup (5 min). For stations, add one activity per rotation with the same length, and the timer moves the class through each one.

    Lesson timer at a glance

    • Free to use with no account
    • Up to 20 activities, each from 1 to 180 minutes
    • Starts the next activity automatically, with an optional chime between activities
    • Named class plans are stored only in this browser
    • No site analytics script on this page
    • Open source under the MIT license, with a downloadable offline copy and source code

    Need a single countdown instead? Use the classroom timer for one activity, such as a transition or a reading block.

# Contributing to Classmade

Teachers are welcome to describe problems or suggest changes without writing code. Use an issue to explain the last time the problem happened, how you handled it, and one outcome that would make it easier. Keep student and personal information out of public issues.

For code changes:

1. Fork the repository and create a branch.
2. Edit the app's files under its `src/` directory.
3. Run `npm test` and `npm run build` from the repository root using Node.js 22+.
4. Open the generated app locally and check its main interactions, keyboard use, and narrow-screen layout.
5. Include the generated `index.html` in your pull request, along with the source edits.
6. Explain the classroom problem, what changed, and how you checked it.

Discuss substantial features in an issue first. We prioritize focused tools with a manageable first version and ongoing maintenance needs. There is no guaranteed build schedule.

Keep tools usable without the Classmade website wherever possible. Avoid adding accounts, tracking, paid services, or external runtime dependencies without discussion.

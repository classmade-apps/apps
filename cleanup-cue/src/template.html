How the cleanup cue works

Enter the time your class ends and how many minutes early you want students to start putting things away. For a 2:45 p.m. bell with two minutes of cleanup, the cue starts at 2:43 p.m. Select Start cue to begin counting down.

When cleanup starts, the display switches to Time to clean up, plays a repeating signal for about four seconds, and counts down to the bell. Select Fullscreen for a projector, or open Cue sound to preview a sound or turn it off.

Use the same bell time on school days

Turn on Repeat on weekdays to use the same time Monday through Friday while the cue is running. Select Stop cue when you want to change the schedule. If you close or reload the page, select Start cue again to enable the countdown and sound.

To use the tool without internet, download Cleanup Cue and open the HTML file in your browser. You can also view the source code on GitHub.

For several timed activities in one class period, use the lesson timer.
